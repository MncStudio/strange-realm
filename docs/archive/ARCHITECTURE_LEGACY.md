# 架构与扩展

## 数据流

浏览器 → Colyseus message → 房间权限与参数校验 → GameEngine 收集行动 → 剧本规则模块统一结算 → 公共和私人投影 → 独立连接。

服务端使用Colyseus 0.16系列。房间生命周期、消息与重连API按 [0.16 Room官方文档](https://0-16-x.docs.colyseus.io/room) 实现；客户端固定 `colyseus.js 0.16.22`，避免跨主版本混用。

原始引擎模型包含角色、物品、线索和待结算行动，只存在服务端内存中。没有将该模型设置为Colyseus同步Schema；服务端将 `PublicSnapshot` 广播给所有连接，将 `PrivateSnapshot` 仅发送给本人。主持没有私人投影。`sync` 消息用于连接后主动读取快照，解决onJoin消息早于浏览器订阅的时序。

## 各包职责

| 模块 | 职责 | 可以依赖 |
| --- | --- | --- |
| shared | 网络类型、消息名 | 无运行时规则依赖 |
| game-engine | 状态机、seeded RNG、行动收集、事件条件、投影 | shared |
| scenarios | 本地JSON、剧本规则模块、剧本注册表 | shared、game-engine |
| server | 身份、连接、权限、消息校验、全员提交检测、房间生命周期 | 三个共享包 |
| web | Vue界面与客户端连接、QR、每标签恢复token | shared；禁止导入engine/scenarios |

## 权限与有效性

创建房间使用浏览器生成的随机 `hostKey`，仅用于首个主持连接鉴权，不返回给公共API。后续不能加入第二个主持，刷新由原会话的Colyseus重连token恢复。玩家身份取自已认证的连接，行动消息不接受 `playerId`、`kind`、`role` 等伪造身份字段。

服务端校验：消息大小、每秒频率、昵称、人数、游戏阶段、回合编号、行动存在、所需物品、目标合法性、一次提交。参数通过复制进入引擎，结算时再次检查仍然有效的物品与目标。物品已被交易或盗走、目标已离场等情况有失败回执，不凭客户端声明执行。

## 确定性结算

一轮内不根据WebSocket到达顺序执行行动。引擎只在收齐所有玩家行动后结算，没有截止时间。主持可明确为未提交的离线者补剧本默认行为；在线者不能被跳过。随后按剧本声明的优先级排序，同优先级用有种子的次序决定。事件从符合世界条件的池中加权抽取，并优先避免同局重复。

剧本定义默认行为、世界初值与上限、动作、事件条件、规则集合及公共flag白名单。规则模块实现身份能力、冲突、规则后果、公共结局与个人目标。剧本真正规则不能只写在告示中，必须由模块执行并进入回放。

## 新剧本接入

1. 参照 `packages/game-engine/src/types.ts` 中的 `ScenarioDefinition`，在scenarios包新增JSON内容和对应规则模块。
2. 模块导出完整定义，配置默认行动（必须无目标且无需物品）及至少一个无条件兜底事件。
3. 加入 `packages/scenarios/src/index.ts` 的注册表；服务端API将自动公布摘要，前端选剧本卡片自动出现。
4. 对规则触发、物品冲突、终局和个人目标写测试；用集成脚本验证投影和联机流程。
5. 若需要新世界指标，可先使用服务端 `world.values/flags` 实现剧本规则；需要公开的新指标时再扩展shared与相应通用展示组件。

## 生命周期边界

大厅主动离开立即释放名额；断线保留180秒用于恢复。游戏中离开仍保留真实角色，等待重连或主持明确补交默认行动。没有长期死亡等待：失踪或离场者仍可使用允许的守候、监听、协助行动。

主持在大厅断线超过重连窗口后房间关闭；游戏中没有时钟推进，主持离线后结果停留等待原会话恢复。空房自动回收，大厅最多保留2小时，终局最多保留30分钟。重开释放所有离线席位并取消旧重连票，离线玩家要重新扫码加入。内存房间无法抵御进程重启，持久化属于后续范围。

## 引导和结果报告

剧本可提供 getPublicGuidance / getPlayerGuidance 回调，分别投影共同目标、指标解释和最多四个入门建议。私人建议只发送本人。引擎保存本轮结算前后值，规则通过 recordWorldChange 记录匿名因果；RoundReport 只含公开变化和下一步方向。身份与请求不进入公共报告。resolution 始终等待主持 advance，终局同样先经过此阶段。deadline 兼容字段固定为 null、roundSeconds 固定为0，不驱动游戏。
