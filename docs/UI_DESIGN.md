# 页面设计 · 雪夜旅馆的来信与卷宗

2026-10-15。使用已安装的 `frontend-design` 技能调整本地网页；故事、服务端权限与游戏规则保持现状。

## 主题与视觉规范

面向围坐的朋友：电脑是共同案桌，手机是本人的卷宗。首页以一封邀请信表达进入故事的动作；调查阶段以原始物证与人物说法的不同材质区分可信度，不通过装饰暗示凶手。

核心颜色：夜色 `#131A23`，桌面 `#242E3B`，信纸 `#E7DFCF`，亮字 `#F2EDE4`，黄铜 `#CCB789`，印章 `#B46E5B`。红色只用于隐私、危险操作与必要状态；物证和角色档案采用纸面深色文字。

字体：本机宋体只用于故事名、姓名与少量标题；本机中文无衬线用于正文与操作；时间使用等宽数字方便横向核对。不加载外部字体，局域网断外网仍可使用。

字号：桌面首页标题约64px，公共阶段约36px，手机标题约28px，正文16～18px，说明13～14px。移动端正文行高1.85，长文本保持单栏。

## 布局草图

首页：故事承载气氛，创建/加入承载操作。文字左对齐，主操作只突出创建，单人试玩保持次级且有剧透提醒。

```text
诡境                                      使用方式
今晚，谁在说谎？              一封写着案件名的邀请信
简短说明                      信纸、封口、正文摘录
发起一局：选故事、创建         收到邀请：填写房间码
```

公共屏：当前阶段在顶部，主要案情与证据在左，六位玩家在右；二维码在大厅展开，游戏中折叠。

```text
阶段进度 / 当前阶段                         房间与连接
案情和已知时间                 六位玩家及完成状态
公共证据板                     邀请二维码（可展开）
人物问题与说法                 中止本局
```

手机：先给当前行动，再提供自己的档案和公共证据。底部保留三个入口；阅读自己的纸面档案时，公开介绍与秘密经历分区。

```text
案件 / 角色 / 当前阶段
当前应该做什么
调查地点 / 我的物证 / 投票
完成本轮的按钮
当前进展       我的档案       公共证据
```

## 设计自查

旧页面大量使用相同深色圆角卡片、英文大写小标题和重复阶段说明。新版把不同信息放在不同材质中：邀请信负责首页焦点，物证为可展开纸面记录，人物说法留在深色桌面，私人档案为独立卷宗。编号只表达真实阶段、证据编号与座位，不人为制造案件参数。

不增加计时、额外剧情、角色能力或复杂菜单。动效只用于信纸的轻微入场及用户展开/选中反馈，并尊重减少动态设置。所有操作保留键盘焦点，触摸控件目标不小于44px。

## 验收

修改完成后记录实际截图与六人/单窗口完整流程结果。视觉改进不代替玩法实测。

### 实际验收结果

- 30项规则与HTTP/SSE测试通过，游戏规则与服务端文件未改动。
- 六个独立手机浏览器跑完整局；单窗口试玩切换角色、完成其余席位、投票和重开通过。
- 检查1440px桌面、1280×720公共屏、390px和320px手机。16:9公共屏首屏可见六人状态，手机无横向溢出。
- 键盘焦点、键盘展开物证、减少动态设置通过。纸面小字的文字/背景对比度已加深。
- 实时更新保留已经收起的物证。模拟手机独立滚动，保持同一视图的阅读位置；切换角色、页面或阶段后回到对应内容顶部。
- 浏览器脚本错误为零。检查截图位于`test-results/`，修改前截图及HTML保存在`test-results/before-redesign/`。

视觉检查对照了首页创建/加入入口、邀请信完整性、角色秘密与公开介绍的区分、物证和人物说法的区分、公共屏六人状态、手机底部导航，以及单窗口试玩左右区域。未引入额外运行依赖或外部字体。

这些结果只验证界面和流程；实体手机、朋友聚会讨论的体验仍需实际试玩。

## 2026-10-18 三人公共屏模式

用户确认三人本故事只在公共屏，手机只做私人卡。沿用夜色、信纸、黄铜与原有字体，不引入新的视觉主题。公共屏先用“为什么来到这里／今晚发生了什么／三位来客”顺序建立共同背景，再进入公开调查和纸票录入；主要内容左对齐，右侧固定保持公开身份。纸票录入按三位玩家分栏填写嫌疑人与判断编号，打印时隐藏案情与操作，只输出三张空白纸票。

手机撤去底部导航和操作按钮。私卡以唯一目的为视觉中心，下面只展开三条事实与当前方向；边界、完整经历和已出现证据的方向可折叠查看。保留16px正文、44px以上公共屏操作目标、键盘焦点与原有减少动态设置。320/390px手机与1280px公屏截图检查通过；六人页面继续沿用前述设计。

新增四人《末班渡口》时，公共关系栏按四人分列，所有人数与纸票文案根据剧本配置渲染；手机仍固定展示三条关键事实，与参与人数无关。打印样式减少段落间距，兼顾四张空票。现有视觉主题与交互流程保持一致。

## 2026-10-19交谈版

沿用现有深色公共案桌、浅色私人卡、衬线标题与金色推进按钮，不另换主题。新公屏的重点是一段新发现和本批原始物证，侧栏仅显示人物与在线状态。取消完成计数、地点登记和发言按钮；当前批次的短物证直接展开，前批可回看。提示、亲历全文和开口方向默认折叠，原物核验主动触发。手机默认仅身份、单目标、三条亲历。纸票和录入表单只有嫌疑人，结局没有判断编号或过程分数。

## 2026-10-21 烛夜主题

在原有结构、交互与字号上叠加一层外观主题（`web/index.html` 中“烛夜主题”区块），不改布局、玩法与服务端。夜色加深为 `#0D0E12`，烛光铜 `#D6B47C`/`#E8C48A` 用于主操作与当前阶段，封蜡红 `#8F2A24` 只用于标记、凶手徽章与提示。背景加入烛光晕、暗角与轻微胶片颗粒；邀请信、物证与私人卷宗使用旧纸渐变与焦边，物证加胶带与轻微倾斜，卷宗加淡“密”印。阶段条改为逐个点亮的烛芯。动效仅限烛光闪烁，继续尊重减少动态设置；手机端取消物证倾斜，打印隐藏背景层。

验收：101项规则测试通过；《闭馆之后》《末班渡口》《人鱼来信》浏览器完整流程通过，无横向溢出与脚本错误。《雪夜来信》浏览器脚本在“保存复盘”下载文件名断言处失败，主题修改前即同样失败，与本次样式无关。
